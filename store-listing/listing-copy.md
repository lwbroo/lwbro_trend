## 完整說明（兩邊共用，4000 字內都夠用）

```
紫微八字，是一個把傳統命理排盤變成每天可以實際使用的個人工具。

【本命盤 + 每日流運】
輸入一次出生日期、時間、性別，App 會排出你的八字本命盤與紫微斗數命盤，並且每天自動算出
當日的流年、流月、流日干支與紫微四化——不用自己翻農曆、查對照表。

【AI 個人化解讀】
每天的流運資料會整合成一段白話的「今日運勢」，不是罐頭文字，是根據你當天實際的十神、
宮位、四化組合生成，涵蓋工作、人際、財務、健康等面向的具體提醒。

【AI 問答】
想知道更多可以直接問——今天適合做什麼決定、這幾天感情運勢如何，AI 會參考你的命盤跟
當日流運回答，可以一直追問下去。

【每日記錄 + 趨勢分析】
每天花幾秒記錄心情、精力、標籤，累積下來可以看到心情狀態跟八字紫微哪些組合有相關性，
是純粹基於你自己資料的觀察，不是通用命理斷語。

【資料完全屬於你自己】
不用註冊帳號也能完整使用，資料存在你自己的裝置上。想要多裝置同步，可以用 GitHub 帳號
一鍵登入，資料存進你自己 GitHub 底下的私密 Gist——我們（開發者）看不到，也拿不到。
沒有廣告，沒有使用行為追蹤，不會把你的資料賣給任何人。

命理內容僅供自我觀察與參考，不是絕對的命定論斷。
```

## Apple「App 隱私」questionnaire 填答對照

Apple 送審會要求逐項回答蒐集了哪些資料類型，照 `privacy.html` 的實際內容，建議這樣答：

| 資料類型 | 是否蒐集 | 用途 | 是否連結使用者身分 |
|---|---|---|---|
| 使用者內容（AI 問答的文字） | 是 | App 功能（產生 AI 回覆） | 否——不與帳號身分連結，只是單次請求內容 |
| 健康與健身（心情/精力記錄）* | 視你怎麼分類 | App 功能 | 否，存在使用者自己裝置或自己的 Gist |
| 其他資料（出生日期/時間/性別） | 是 | App 功能（排盤用） | 否 |
| 聯絡資訊 | 否 | — | — |
| 位置、瀏覽紀錄、識別碼、使用行為分析 | 否 | — | — |

*「心情記錄」算不算 Health & Fitness 類別的敏感資料，Apple 的問卷選項每次改版用詞會不同，
送審當下照問卷實際選項判斷即可，抓「有記錄但不分享給第三方、不做廣告用途」這個原則去選。

## 還需要你自己做的事（我這邊做不到的部分）

1. **App Store Connect / Google Play Console 帳號**——分別要 $99/年、$25 一次性
2. **確認 App 名稱沒有撞名**
3. **實機截圖**——`store-listing/screenshots/` 裡已經有 5 張草稿（今日流運、本命盤、
   記錄、趨勢分析、AI 問答），用瀏覽器模擬 iPhone 尺寸（393×852pt @3x）產生，內容是
   示範資料不是真人資料。正式上架建議用真的原生 App（Capacitor 包好之後）在實機或
   模擬器上重新截一次會更準，兩邊商店對截圖尺寸/張數要求偶爾會變，送審當下以
   Console 裡的即時規格為準
4. **年齡分級問卷**、**App 隱私 questionnaire**——上面表格是對照建議，實際要在
   Console 裡逐題勾選
