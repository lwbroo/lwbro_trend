# App Store Connect — App Review 備註

送審時貼進 **App Review Information → Notes**。送出前把方括號裡的內容填好。

## Demo 帳號
不需要——紫微八字沒有強制登入。審核流程：
1. 打開 App，會先看到「設定」頁，填出生日期、時間、性別（任何合理值都可以）
2. 儲存後自動跳到「今日流運」，會看到當天的八字流運、紫微流運表格，以及
   一段 AI 生成的「今日運勢」解讀
3. 「本命盤」分頁：紫微斗數十二宮盤（橫向可滑動）
4. 「AI 問答」分頁：可以直接輸入問題（例如「今天適合做什麼」），AI 會參考
   使用者的命盤資料回答
5. 「記錄」「趨勢分析」分頁：一開始是空的，在「今日流運」底部填一筆心情/
   精力記錄後就會有資料可以看
6. 「設定 → 雲端同步」：選用功能，點「使用 GitHub 登入」會走標準 GitHub
   OAuth 流程，不測試這個也不影響其他功能的審核

## 為什麼需要網路權限
App 需要網路存取來：
- 排盤引擎（lunar-javascript／iztro）已經內建在 App 裡，不需要網路
- 「今日運勢」與「AI 問答」需要呼叫後端（Cloudflare Worker）取得 AI 生成內容
- 「雲端同步」（選用）需要呼叫 GitHub API

沒有網路連線時，排盤跟本地記錄功能完全正常，只有上述 AI 功能與雲端同步
無法使用。

## 命理內容的定位——為什麼不是誤導性內容
紫微八字提供的是**自我觀察與參考用**的命理排盤與趨勢分析，不是：
- 醫療、心理、財務、法律建議
- 對未來事件的確定性斷言

App 內文案刻意避免「一定會」「大凶」之類的絕對化用詞（AI 生成內容的系統
提示詞明確要求語氣溫和務實），並在多處標示「僅供自我觀察參考」。

## AI 功能的說明
- 「今日運勢」「AI 問答」由 xAI 的 Grok 模型生成，根據使用者當天已經算好的
  八字／紫微流運資料（干支、十神、宮位等衍生資料）回答，**不會**收到使用者
  的姓名或完整生日
- 目前這兩個功能對所有使用者免費，只有每日呼叫次數上限（防止濫用，非付費
  限制）——App 內沒有任何訂閱或付費功能
