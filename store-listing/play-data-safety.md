# Google Play Console — Data Safety 表單參考

照著填 **Play Console → App content → Data safety**。表單實際的用詞、分類
Google 會不定期調整，這份文件是給「該怎麼答」的參考依據，不是逐字照貼。

## 這個 App 有蒐集或分享受規範的使用者資料嗎？
**有。**

## 蒐集的資料類型

### Personal info → Other info（出生日期、時間、性別、選填姓名）
- **蒐集**：有——用來排八字紫微本命盤。
- **分享**：
  - 預設不分享——只存在使用者自己裝置的 localStorage
  - 使用者自己選擇開啟「雲端同步」時：存進**使用者自己的 GitHub 帳號**
    （私密 Gist），不是 App 開發者的伺服器，開發者本人看不到內容
  - AI 功能（今日運勢／AI 問答）只會送出**已經算好的衍生資料**（干支、
    十神、宮位名稱等），不會送出姓名或完整生日本身，處理方是 xAI（Grok）
- **是否為必要功能**：是——排盤是這個 App 的核心功能，沒有這筆資料無法使用。

### Device or other IDs（隨機產生的裝置識別碼）
- **蒐集**：有——前端隨機產生、存在 localStorage 的一組匿名 ID，不是硬體
  識別碼（不是 Android ID／廣告 ID）。
- **分享**：跟 AI relay（Cloudflare Worker）分享，純粹用來做每日用量上限
  （防止單一裝置刷爆 AI API 額度），不落地、不建檔案、不建立使用者輪廓。
- **用途**：App 功能（防濫用）。
- **是否為必要功能**：否——不影響排盤跟本地記錄功能，只影響 AI 個人化
  解讀／問答這兩個附加功能的使用量控管。

### App activity（技術性錯誤診斷，不是使用行為分析）
- **蒐集**：有，但只在 App 發生錯誤時才會送出——錯誤訊息、發生在哪個檔案／
  行數、瀏覽器版本，用來讓開發者知道哪裡壞了。
- **分享**：跟 AI relay 分享，即時印出到 log，不落地儲存、不含使用者輸入的
  任何內容。
- **用途**：App 功能（除錯）。
- 這**不是**傳統的使用行為分析／追蹤——沒有埋點記錄使用者點了什麼、待了
  多久之類的行為資料。

## 明確沒有蒐集的資料類型
以下都可以直接答「否」——程式碼裡沒有任何機制蒐集這些：
- 姓名以外的個人識別資訊（email、電話、地址）
- 位置（精確或概略）
- 通訊錄
- 照片、影片、音訊、檔案
- 財務資訊（目前沒有任何付費/內購功能）
- 訊息內容（AI 問答輸入的文字不算「訊息」類別，屬於上面 App activity/
  Personal info 已經涵蓋的範圍）
- 網頁瀏覽紀錄
- 廣告識別碼（沒有廣告、沒有廣告 SDK）
- 傳統使用行為分析／熱點圖／點擊追蹤

## 每日心情記錄的說明
使用者記錄的心情、精力、標籤、筆記，儲存邏輯跟出生資料完全一樣——預設只在
本機 localStorage，使用者主動開啟雲端同步才會存進**使用者自己的** GitHub
Gist。不會傳到開發者的伺服器，也不會用於分析或分享給第三方。

## 安全性作法區塊
- **傳輸過程加密**：是（跟 GitHub API、AI relay 之間都是 HTTPS）
- **使用者可以要求刪除資料**：可以——本機資料在「設定 → 資料管理 → 清除
  全部資料」隨時可刪；雲端資料是使用者自己 GitHub 帳號底下的 Gist，使用者
  自己到 gist.github.com 就能刪除，不需要聯絡開發者
- **獨立資安審查**：否（小型獨立開發專案，除非之後有變動否則答「否」）
