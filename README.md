# 紫微八字 · 個人趨勢資料庫

個人專屬的紫微斗數＋八字線上排盤程式：每天用它查看自己的**流年／流月／流日**，
順手記下當天的**心情、精力與狀態**，累積成個人資料庫後，
自動統計「哪種流日我的狀態最好／最差」，把傳統命理變成可驗證的個人趨勢觀察。

## 功能

- **今日流運**：任選日期，同時顯示
  - 八字視角：流年／流月／流日干支、五行、對你日主的十神關係（立春換年、節氣換月）
  - 紫微視角：流年／流月／流日四化（祿權科忌）、該層命宮落在本命盤的宮位與主星
- **本命盤**：
  - 紫微斗數 12 宮盤（主星亮度、生年四化、大限、身宮，並標記今日的流年／流月／流日命宮與流運四化）
  - 八字四柱（十神、藏干、納音）與五行分佈
- **每日記錄**：心情 1–5、精力 1–5、狀態標籤（可自訂）、自由筆記，每日一筆可隨時補記與修改
- **趨勢分析**：
  - 心情／精力時間走勢（提示框附當日干支）
  - 平均心情（或精力）× 流日天干五行／流日十神／流日天干／流日地支／紫微流日命宮
  - 自動摘要：樣本數 ≥3 的分組中，狀態最高與最低的流日類型
- **資料庫管理**：JSON 匯出／匯入（跨裝置合併）、CSV 匯出（含排盤欄位，可丟進試算表分析）

## 使用方式

純靜態網頁，無需安裝、無後端：

```bash
# 方法一：直接用瀏覽器開啟 index.html
# 方法二：起一個簡單的 HTTP 伺服器
python3 -m http.server 8000
# 然後開 http://localhost:8000
```

也可以直接部署到 GitHub Pages（Settings → Pages → 從分支部署根目錄）。

第一次使用：到「設定」輸入出生年月日、時間（當地時間）與性別 → 儲存並排盤。
之後每天到「今日流運」看盤並記錄狀態即可。

## 隱私

所有資料（出生資料與每日記錄）只存在**你自己瀏覽器的 localStorage**，
不會上傳到任何伺服器。清除瀏覽器資料前請先「匯出 JSON」備份；
換裝置時匯入備份即可無縫合併。

## 專案結構

```
index.html        單頁應用入口
css/style.css     樣式
js/engine.js      排盤引擎（八字十神／流日干支／紫微流運，含批次分析器）
js/store.js       localStorage 資料庫（記錄、匯出／匯入／合併）
js/charts.js      SVG 圖表（折線圖、長條圖，含 hover 提示）
js/app.js         UI 主邏輯
vendor/           排盤函式庫（lunar-javascript、iztro，皆 MIT）
                  預設自動從 CDN 載入鎖定版本；想離線使用
                  請依 vendor/README.md 下載兩個檔案放入此資料夾
```

## 排盤規則說明

- 八字：以**立春**換年柱、**節氣（節）**換月柱；十神以本人日主推算，地支另列本氣十神與藏干。
- 紫微：採 [iztro](https://github.com/SylarLong/iztro) 預設（中州派）安星與四化規則；
  流年／流月／流日命宮及各層四化由 `horoscope()` 計算。
- 時辰：23:00 起算晚子時（iztro 時辰索引 12）。

> 命理內容僅供自我觀察與紀錄參考，趨勢統計呈現的是個人資料的相關性，並非因果推論。
