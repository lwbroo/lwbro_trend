雲端同步 （GitHub Gist，選用）

開啟後，資料會同步存到你自己 GitHub 帳號的私密 Gist，家裡、辦公室、手機都能同步使用；不經過任何第三方伺服器。

進階：改用 Personal Access Token 連線

到 GitHub 建立一個 Personal Access Token（只勾 gist 權限即可）→ 貼到下面 → 連線。

Token

「同步連結」＝在其他裝置免輸入 Token 的一鍵連線網址：存到書籤或用通訊軟體傳給自己， 新裝置（含手機）打開這條連結就自動連上同一份雲端資料。此連結等同你的資料鑰匙，請勿分享給別人。

資料管理

未開啟雲端同步時，所有資料只儲存在你的瀏覽器（localStorage）。換裝置或清瀏覽器資料前，請先匯出 JSON 備份或開啟雲端同步。
