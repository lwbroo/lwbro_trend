紫微八字 隱私權政策

最後更新：2026-09-04

這是什麼

紫微八字是一個個人開發的排盤／每日記錄工具，用你的出生資料計算八字與紫微斗數， 協助你觀察自己的每日流運與心情記錄的關聯。這份政策說明這個 App 會蒐集什麼資料、 存在哪裡、經過哪些第三方服務——不是制式的法律範本，是照這個 App 實際的運作方式寫的。

會蒐集哪些資料

  • 出生資料——姓名（選填）、出生日期、出生時間、性別，用來計算你的本命盤
  • 每日記錄——你自己填寫的心情、精力、標籤、備註
  • AI 問答的對話內容——你在「AI 問答」分頁輸入的問題

不會蒐集：廣告識別碼、裝置指紋、使用行為分析、你的真實姓名以外的任何身分資訊。

唯一的例外：App 發生錯誤時，會回報純技術性的診斷資訊（錯誤訊息、發生在哪個檔案/ 行數、瀏覽器版本），幫助開發者知道哪裡壞了並修好，不含你輸入的任何內容，也不會 連結到你的身分。

資料存在哪裡

預設情況：以上資料只存在你自己裝置的瀏覽器本地儲存空間（localStorage）， 不會傳到任何伺服器，我們（開發者）完全看不到、也拿不到。清除瀏覽器資料或換裝置， 這些資料就會消失（App 內建「匯出 JSON」可以自己備份）。

如果你選擇開啟「雲端同步」：資料會存進你自己 GitHub 帳號底下的私密 Gist， 這是 GitHub 官方帳號功能，不是我們自己的伺服器，開發者一樣無法讀取你的 Gist 內容 （除非你自己選擇分享）。

用到哪些第三方服務

  • GitHub——選擇開啟雲端同步時，用來做登入驗證與存放你的資料（私密 Gist）。 受 GitHub 隱私權聲明 規範。
  • Cloudflare——App 用兩個極簡單的 Cloudflare Worker 當中繼站 （一個做 GitHub 登入的 token 交換、一個轉發 AI 請求），這兩個中繼站不記錄、不儲存 任何請求內容，純粹轉發。
  • xAI（Grok）——「今日運勢」與「AI 問答」功能會把你當天的八字／紫微流運計算結果 （干支、十神、宮位等命理衍生資料，不含姓名或完整生日）以及你在 AI 問答輸入的文字， 送給 xAI 的 Grok 模型生成回覆內容。受 xAI 隱私權政策 規範。

不會做的事

  • 不投放廣告，不做任何使用行為追蹤或分析
  • 不會把你的資料出售或分享給廣告商、行銷公司
  • 不會用你的資料訓練任何模型

你可以自己控制的事

  • 「設定 → 資料管理 → 匯出全部資料（JSON）」——隨時備份
  • 「設定 → 資料管理 → 清除全部資料」——刪除裝置上的所有資料
  • 「設定 → 雲端同步 → 中斷連線」——停止同步，本機資料保留
  • 想徹底刪除雲端資料，可以到你自己的 GitHub 帳號（gist.github.com）手動刪除對應的 Gist

兒童隱私

這個 App 不是特別針對兒童設計，也不會刻意蒐集兒童的個人資料。
