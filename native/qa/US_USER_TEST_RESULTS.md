# Ziwei simulated US first-user review — 2026-10-06

The offline app's synthetic profile, chart navigation, journal save/restart/update, calendar, two-entry trends, local privacy return, import errors/merge and a real nonempty local Files roundtrip were exercised through the UI. It is not ready for an English-only US first-time user: the product UI, chart terminology and important privacy/timezone explanations remain Traditional Chinese. This is simulated QA, not customer validation or proof of international astrology accuracy.

The [plan](US_USER_TEST_PLAN.md) was shared before execution. App runtime source was `9f737e089583889df5e6abc2264b222722940145`, Release, `com.lwbroo.ziweibazi`, 1.0/build 1. The original project at `/Users/kurtchiang/AI/ziwei-bazi/lwbro_trend` retains its two untracked `.wrangler/` directories; this work stays in the isolated checkout.

The owned iPhone 17 Pro simulator ran iOS 26.5, UUID `C6DEE62B-0F41-4C39-BAB3-4BCBC32DACEB`. For a reproduction, overlay this class into NativeChecks only in a disposable Release staging checkout, use a newly owned simulator, run methods in plan order with `-only-testing`, and adapt the date fixtures to the actual tested environment. Preserve evidence and delete only that exact simulator afterward. Normal `NativeChecks.swift` was restored byte-for-byte.

Discovery attempts used incorrect XCTest locators for HTML date controls, time-wheel values, the calendar's `Today` prefix, share dismissal and the local root title. Each was corrected from captured actual hierarchy. Failed locator runs are not App defects. Conda compiler overrides initially blocked Xcode build; sanitizing only the child build environment resolved it, with no software install or global change. Xcode's failure-diagnostic collector also could not locate simctl in some failed runs; successful actual UI captures remain valid.

No new software dependencies, credentials, account/storefront changes, AI/network features, public deployment, App Store actions or physical phone control were performed. The reviewed App and XCTest runner were installed only on the disposable simulator. Product target documents now say United States first/global; actual storefront selections remain unapproved/unmodified.
